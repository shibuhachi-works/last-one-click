# v0.1.5

本文の画像(とくに gif)が入りやすくなり、拡張が進めているあいだの様子が画面で分かるようにした版です。現在は note に対応しています。

## 変わったこと

- 本文の gif を、入るまで長めに待つようにしました
  - gif は note の側の処理に時間がかかることがあるので、2 分まで待ちます(ほかの画像は今までどおり 30 秒)。入った時点で次に進むので、うまく入るときの速さは変わりません
  - 待ちきれなかった画像も、すべての画像を入れ終えたあとに、もう一度確かめます。遅れて入っていれば、目印を消してキャプションを入れます
  - 遅れて入った画像は、その画像のものと分かるときだけ確定します(ほかの画像の目印を消したり、キャプションを入れたりしません)
  - note のダイアログ(「画像アップロード中です」など)が出ていて、ページが止まっていた時間は、待ち時間に数えません
- 拡張が進めているあいだの様子を、画面右下のバナーに出すようにしました
  - いま何をしているか(「本文の画像を入れています(1/3 枚目: demo.gif)」など)と、待っている秒数を出します
  - 進めているあいだは、回る印と「処理中です。終わるまで、この画面は操作せずにお待ちください」を出します。確かめるボタンが出たときや、終わったときは消えます
  - バナーを「たたむ」で小さくしても、秒数が進むたびに開いてしまうことはありません
- 本文の gif が入らなかったときは、直し方(横幅を 620px 以下にする、YouTube の動画にするなど)をバナーに出すようにしました
- 案内の文に出てくるボタンの名前を、実際のボタンの文字「note の下書きを作成」に合わせました
- 診断(「拡張機能の設定」→「診断(動かないとき)」)の結果に、記事のタイトルや本文の文字を入れないようにしました。書ける欄は、文字の長さだけを出します
- 見本の記事 [templates/note](https://github.com/shibuhachi-works/last-one-click/tree/v0.1.5/templates/note) に、動く画像(gif)の例 `image2.gif` を足しました
- 不具合の報告と、質問・要望を送るための Issue のテンプレートを足しました
- 拡張とストアの説明文で、下書きが「自動で」できることが伝わる言い方にしました

## 変えていないもの

- 権限(`host_permissions`)、note の Cookie・パスワードに触れないこと、記事を送るサーバーを持たないこと、公開ボタンを押さないこと
- note のダイアログには触れません(閉じたり、置き換えたりしません)。「OK」は人が押します

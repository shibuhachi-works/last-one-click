# v0.1.2

拡張の名前を「**Last One Click**」(ラストワンクリック)に変えた版です。名前と説明が変わっただけで、動きは v0.1.1 と同じです。現在は note に対応しています。

## 変わったこと

- 名前を「Lastclick Pigeon for note」から「Last One Click」に変えました。1 つの拡張で、対応するサービスを増やしていくための名前です(現在は note に対応)
- ポップアップ・ページ内のバナー・診断レポートの表示名を、新しい名前にしました
- ストアの説明に、md ファイルの書き方(先頭の `title` / `hashtags` / `magazine`)を足しました
- ストアに載せる画像を、新しい名前で作り直しました

## 入手

- Chrome ウェブストア: https://chromewebstore.google.com/detail/lastclick-pigeon-for-note/jomapffkhcdpnodaffobmpfofnnaihnd
- 使い方は [extension/README.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.2/extension/README.md)、プライバシーポリシーは [docs/PRIVACY.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.2/docs/PRIVACY.md)

## 変えていないもの

- 権限(`host_permissions`)、note の Cookie・パスワードに触れないこと、記事を送るサーバーを持たないこと、公開ボタンを押さないこと
- ストアの URL と、拡張の ID

不具合は Issues へ。ライセンスは MIT です。

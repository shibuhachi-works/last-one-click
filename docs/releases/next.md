# 次の版(まだストアに出していない)

ストアに出ている版(v0.1.7)のあとに main にマージした、利用者に関係する変更をためておく所です。ここにある機能は、次の版(v0.1.8)がストアで公開されるまで、ストアから入れた拡張では使えません。

- 拡張の動きを変える PR は、同じ PR でここに 1 行足す(見張り役(`tools/`)・テストだけの変更は書かない)
- リリースの PR で、このファイルを `docs/releases/v0.1.8.md` にし、空の `next.md` を作り直す(手順は [docs/store-submission.md](../store-submission.md))

## 変わったこと

- front matter に `target:`(入れる先)を書けるようにした。書かないか `note` なら今までどおり。それ以外の値を書いた記事は、note の下書きを作らずに止まる(note 以外のサイトに出す記事を、うっかり note に入れないため。値は自由)
  - 止めるのは、記事を読み込んだ時点。知らせを出して「note の下書きを作成」を押せなくする(押してから止めるより先に分かるように)
- 本文の HTML コメント(`<!-- … -->`)を、下書きに入れる前に取り除くようにした。md に書いた自分用のメモの枠が、本文に文字として入らない(コードの中に書いたものは残す。閉じていない `<!--` は文字のまま出す)
- 画面に出る文のうち、「この画面」「このページ」「このアカウント」のように指す先があいまいなものを、「note の編集画面」「今開いているページ」「作成に使った note のアカウント」のように、何を指すか分かる言い方にした

## 変えていないもの

- 追加の対応先の編集画面に入れるときは、note にだけある設定(目次・URL の埋め込み・マガジン・価格・最後のクレジット)を押せなくし、「(このページでは使えません)」と添える。入らない書き方の知らせにも出さない(開発用のビルドだけ)
- 追加の対応先の入口は、ストアの版では今までどおり出さない(開発用のビルド `EXTRA_SITE=1 npm run build` でだけ有効にして、そのエディタの診断を取れるようにした。#118)
- 追加の対応先の「使えるようにする」の案内は、開発用のビルドで、そのサイトのどのページ(エディタでなくてもよい)でも出るようにした。エディタ以外のページでは、使えるようにしてから新規記事エディタを開くよう案内する
- 追加の対応先の下書きの入力も、開発用のビルドでだけ動く。その編集画面のタブでポップアップを開くと、ボタンが「今開いているページに下書きを入れる」になり、今のタブにタイトル・本文・画像・タグを入れて止まる(「確認画面へ」「下書き保存」は押さない。#120)

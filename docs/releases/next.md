# 次の版(まだストアに出していない)

ストアに出ている版(v0.1.5)のあとに main にマージした、利用者に関係する変更をためておく所です。ここにある機能は、次の版(v0.1.6)がストアで公開されるまで、ストアから入れた拡張では使えません。

- 拡張の動きを変える PR は、同じ PR でここに 1 行足す(見張り役(`tools/`)・テストだけの変更は書かない)
- リリースの PR で、このファイルを `docs/releases/v0.1.6.md` にし、空の `next.md` を作り直す(手順は [docs/store-submission.md](../store-submission.md))

## 変わったこと

- md の front matter に `price: 300` のように書くと、公開設定で記事タイプの「有料」を選び、価格を入れるようにしました(ポップアップの「価格(有料)」の欄で直せます)。「有料エリア設定」は押さないので、どこから有料にするかは note の画面で決めてください
- `price` と一緒に、本文に `<!-- ここから有料 -->` だけの行を書くと、公開設定で「有料エリア設定」を押し、その行の直前の段落のすぐ下に有料エリアのラインを引いて止まるようにしました(印が無ければ、これまでどおり「有料エリア設定」は押しません)
- 診断(「拡張機能の設定」→「診断(動かないとき)」)の「コピー」を押したとき、コピーできたことをボタンの上に「コピーしました ✓」と出すようにしました(少したつと元の「コピー」に戻ります)
- 診断のレポートに、節「ログイン中のアカウントの手がかり」を足しました(アイコンらしい画像・プロフィールらしいリンク・ページに埋め込まれたデータのキー・メニューを開くボタンが、どこにあるか)。名前・ID・アイコンの URL などの中身は出さず、レポート全体からも伏せます
- 「拡張機能の設定」のバージョン表示の下に、使い方の記事(note)へのリンクを足しました(新しいタブで開きます)
- 有料記事の見本 [templates/note-paid](https://github.com/shibuhachi-works/last-one-click/tree/main/templates/note-paid) を足しました(`price` と `<!-- ここから有料 -->` の使い方)

## 変えていないもの

- 権限(`host_permissions`)、note の Cookie・パスワードに触れないこと、記事を送るサーバーを持たないこと、公開ボタンを押さないこと

# v0.1.7

ログイン中の note アカウントのアイコンと名前を、ポップアップと編集画面のバナーに出すようにした版です。アカウントを 2 つ持っているときに、違うアカウントで投稿しないためです。現在は note に対応しています。

## 変わったこと

- ポップアップの「note の下書きを作成」のすぐ上に、「ログイン中: [アイコン] 名前」を出すようにしました
  - note のタブを開いていなくても出ます(このときだけ、拡張から note.com に 1 回問い合わせます)
  - 投稿したいアカウントと違っていたら、note でアカウントを切り替えてから作成してください
- 編集画面の右下のバナーに、「このアカウントで作りました: [アイコン] 名前」を出すようにしました(下書きを入れ終えたときと、公開設定を入れたあと)
  - 読めなかったときは何も出さず、下書きの作成はそのまま続けます
- アカウントは、ログイン中のユーザーの情報を返す note の問い合わせ(GET)に 1 回だけ問い合わせて読みます。Cookie は読みません。名前とアイコンは画面に出すだけで、保存も、note.com 以外への送信もしません。問い合わせるのは、ポップアップを開いたとき・下書きを入れ終えたとき・公開設定を入れたあと・診断のときだけです
- 診断(「拡張機能の設定」→「診断(動かないとき)」)の「ログイン中のアカウントの手がかり」に、この問い合わせの結果(応答の有無・状態・道筋と文字数だけ。値は伏せます)を足しました。また、同じ形の記事一覧が先にあっても、アカウントの手がかりが欠けないようにしました
- 本文の Markdown を変換する部品(marked)を 18.2 に新しくしました。太字・斜体の閉じ方や、入れ子の箇条書きの中の見出し・コードの後の文が、より正しく変換されます

## 変えていないもの

- 権限(`permissions` と `host_permissions`)。`cookies` 権限は持ちません。記事を送るサーバーを持たないこと、公開ボタンを押さないこと
- 「投稿する」「有料で公開する」は押しません。最後の 1 クリックは人が押します

# v0.1.4

md にファイル名で書いた画像(`![説明](image1.png)`)を、note の本文のその位置に入れられるようにした版です。画像のキャプション、記事のフォルダ・ZIP のドロップ、記事の最後のリンクとハッシュタグ #LastOneClick のチェックを外に出す変更も入っています。現在は note に対応しています。

## 変わったこと

- 本文の画像を入れられるようにしました
  - md に `![説明](image1.png)` のようにファイル名で書いた画像を、note の本文のその位置に入れます(URL で書いた画像は、これまでどおりです)
  - GitHub から読み込んだときは記事と同じフォルダから、手元の md のときは一緒にドロップした画像から取ります
  - 1 記事 20 枚・本文と見出し画像と合わせて約 6MB まで。入れられなかった画像は、本文に目印(［画像1・…: image1.png］)を残して、画面右下のバナーで知らせます
  - 「記事の設定」に「本文の画像を入れる」を足しました(最初からチェックあり)
- `![説明](image1.png "キャプション")` のように `"…"` を書くと、画像の下のキャプションにも入れるようにしました(`説明` の部分は入れません)
- 記事のフォルダや、md と画像をまとめた ZIP を、そのままドロップできるようにしました
  - 本文に書いた画像は本文の画像に、front matter の `thumbnail` に書いた画像は見出し画像にします
  - md が 2 つ以上あるときは、`article.md` か `index.md` を記事として読みます
  - ZIP は md と画像で合わせて 60MB・1000 個まで。パスワード付きの ZIP は読めません
  - 「md ファイルを選ぶ」からも ZIP を選べます
- 記事の最後のリンクのチェックを、「記事の設定」の中から外に出しました
  - 文言を「記事の最後に『Last One Click で下書きしました』のリンクと、ハッシュタグ #LastOneClick を入れる」にし、リンクとハッシュタグの両方が入ることを書きました
  - チェックが入っていると、ハッシュタグに #LastOneClick を足します(md にすでにあれば足しません)。最初からチェックあり、外すとどちらも入りません
- 見本の記事 [templates/note](https://github.com/shibuhachi-works/last-one-click/tree/v0.1.4/templates/note) に、本文の画像(キャプション付き)の例と画像 `image1.png` を足し、ハッシュタグを意味のあるもの(#LastOneClick ほか)にしました
- GitHub から読み込んだ記事を「読み込んだ内容」の欄で少し直しても、画像を同じフォルダから取るようにしました(欄を空にしたときと、全体を貼り替えたときは取り直します)
- ストアの説明文を、今の機能に合わせて書き直しました

## 入手

- Chrome ウェブストア: https://chromewebstore.google.com/detail/last-one-click/jomapffkhcdpnodaffobmpfofnnaihnd
- 入手・紹介ページ: https://shibuhachi.works/last-one-click/
- 使い方は [extension/README.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.4/extension/README.md)、プライバシーポリシーは [docs/PRIVACY.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.4/docs/PRIVACY.md)
- 拡張でできることは、見本の記事 [templates/note](https://github.com/shibuhachi-works/last-one-click/tree/v0.1.4/templates/note) を「GitHub から読み込む」で読み込むか、フォルダごとドロップして試せます

## 変えていないもの

- 権限(`host_permissions`)、note の Cookie・パスワードに触れないこと、記事を送るサーバーを持たないこと、公開ボタンを押さないこと
- 画像は拡張の中だけで扱い、外のサーバーには送りません(note にはエディタへの貼り付けで入れます)

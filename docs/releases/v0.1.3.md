# v0.1.3

設定の間違いを防ぐ改善と、ホームページ URL の更新の版です。下書きを組み立てる動きは v0.1.2 と同じです。現在は note に対応しています。

## 変わったこと

- 設定の「selectors/note.json の URL」に、記事の URL を入れて保存できないようにしました。`.json` でない URL を入れて「保存」を押すと、「記事の URL は、上の『GitHub から読み込む』に貼ってください」と案内して、保存しません
- すでに間違った URL を保存していた場合も、既定の URL で note の画面の定義を読むようにしました(更新するだけで直ります)
- 「上級者向けの設定を表示する」にチェックを入れているときは、画面の上の「GitHub から読み込む」を最初から開いておくようにしました
- 拡張の `homepage_url` を https://shibuhachi.works/last-one-click/ に更新しました
- Markdown の変換に使うライブラリ(marked)を 18.1.2 に更新しました

## 入手

- Chrome ウェブストア: https://chromewebstore.google.com/detail/last-one-click/jomapffkhcdpnodaffobmpfofnnaihnd
- 入手・紹介ページ: https://shibuhachi.works/last-one-click/
- 使い方は [extension/README.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.3/extension/README.md)、プライバシーポリシーは [docs/PRIVACY.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.3/docs/PRIVACY.md)
- GitHub から読み込む機能は、見本の記事 [templates/note](https://github.com/shibuhachi-works/last-one-click/tree/v0.1.3/templates/note) で試せます

## 変えていないもの

- 権限(`host_permissions`)、note の Cookie・パスワードに触れないこと、記事を送るサーバーを持たないこと、公開ボタンを押さないこと
- 拡張の ID とストアの URL

不具合は Issues へ。ライセンスは MIT です。

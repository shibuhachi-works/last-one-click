# v0.1.3

記事の先頭に目次を入れる機能と、URL だけの行を埋め込み(カード)にする機能を足した版です。日本語の `**「…」**` が太字にならなかった問題の修正、記事の最後に入る 1 行、設定の間違いを防ぐ改善、ホームページ URL の更新も入っています。現在は note に対応しています。

## 変わったこと

- ポップアップに「記事の先頭に目次を入れる」を足しました。チェックを入れると、本文の先頭に note の目次(本文の見出しから note が作るもの)を入れます。チェックは次回も覚えています。目次を入れられなかったときは止まらずに先へ進み、画面右下のバナーで知らせます
- ポップアップに「URL だけの行を埋め込みにする」を足しました。チェックを入れると、本文の中で URL だけが書かれた行を、note の埋め込み(カード)にします。文の中のリンクはそのままです。1 記事 20 件までで、それを超えた分と埋め込みにできなかった URL は行のまま残し、バナーで知らせます
- 下書きを作り終えたら、エディタのいちばん上(タイトル)に画面を戻すようにしました。本文を貼ったあとも、記事を上から確かめられます
- 日本語の文で、かぎかっこや句読点ごと太字にした `**「…」**` の形が太字にならず、`**` が本文に残っていたのを直しました(斜体の `*「…」*` も同じ)
- 記事の最後に「この記事は、Last One Click で下書きしました。」の 1 行(ストアへのリンク付き)を入れるようにしました。ポップアップのチェックを外すと入りません。チェックは次回も覚えています
- 見本の記事 [templates/note](https://github.com/shibuhachi-works/last-one-click/tree/v0.1.3/templates/note) に、拡張でできること(太字・コード・URL の埋め込み・目次・最後の 1 行など)を全部入れました。「GitHub から読み込む」に貼って「読み込む」を押せば、そのまま下書きにして試せます
- 設定の「selectors/note.json の URL」に、記事の URL を入れて保存できないようにしました。`.json` でない URL を入れて「保存」を押すと、「記事の URL は、上の『GitHub から読み込む』に貼ってください」と案内して、保存しません
- すでに間違った URL を保存していた場合も、既定の URL で note の画面の定義を読むようにしました(更新するだけで直ります)
- 「上級者向けの設定を表示する」にチェックを入れているときは、画面の上の「GitHub から読み込む」を最初から開いておくようにしました
- 拡張の `homepage_url` を https://shibuhachi.works/last-one-click/ に更新しました
- Markdown の変換に使うライブラリ(marked)を 18.1.2 に更新しました

- 入手・紹介ページ: https://shibuhachi.works/last-one-click/
- 使い方は [extension/README.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.3/extension/README.md)、プライバシーポリシーは [docs/PRIVACY.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.3/docs/PRIVACY.md)

## 変えていないもの

- 権限(`host_permissions`)、note の Cookie・パスワードに触れないこと、記事を送るサーバーを持たないこと、公開ボタンを押さないこと
- 拡張の ID とストアの URL

不具合は Issues へ。ライセンスは MIT です。

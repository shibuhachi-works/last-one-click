# v0.2.0

note のほかに、追加の対応先(note のほかのサイト)の記事の編集画面にも下書きを入れられるようにした版です。対応するサイトが増えたので、版を v0.2.0 にしました。

## 変わったこと

- 追加の対応先の記事の編集画面にも、下書きを入れられるようにしました
  - そのサイトのページ(記事の一覧など、エディタでなくてもよい)でツールバーのアイコンを押し、ポップアップの「使えるようにする」で許可した人だけが使えます。許可は、ポップアップの「記事の設定」のスイッチでいつでも外せます
  - 許可したサイトの記事の編集画面(新規でも下書きでもよい)でポップアップを開くと、ボタンが「今開いているページに下書きを入れる」になります。新しいタブは開かず、今のタブにタイトル・本文・記事の設定(外部公開の範囲・カテゴリ・要約・読了目安時間・タグ)・見出し画像・本文の画像(png・jpg)を入れて止まります
  - 記事の設定を画像より先に入れ、画像を上げたあとはページの自動保存が落ち着くのを待ってから、タグとカテゴリが残っているかを確かめます。消えたタグは 1 回だけ入れ直します
  - 拡張は「下書き保存」「確認画面へ」を押しません。中身を確かめてから、自分で押してください
  - 編集画面以外のページからでも、front matter の `target:` が note 以外の記事なら、そのサイトの新規記事を新しいタブで開いて入れます(ログインしていなければ、ログインし終えて編集画面に移るまで待ちます)
  - ポップアップには、そのサイトのログイン中のアカウント(アイコンと名前)を出します。note のアカウントの行と、note にだけある設定(目次・埋め込み・マガジン・価格・最後のクレジットなど)は出さないか、押せなくして「(このページでは使えません)」と添えます
  - front matter に `summary:`(要約)・`category:`(「大きなカテゴリ > 小さなカテゴリ」か小さなカテゴリだけ)・`外部公開:`(全文公開 / 冒頭のみ公開)・`読了目安時間:`(表示する / 表示しない)を書けます。note には入れません
  - 入れるときの権限の警告は増えません(`activeTab`・`scripting` と、そのサイトだけを後から許可する `optional_host_permissions` を使います)
- ポップアップのいちばん下の版をマウスで押したとき、版のまわりに青い枠(フォーカスの枠)が残らないようにしました。Tab キーで移ったときは、今までどおり枠が出ます

## 入手

- Chrome ウェブストア: https://chromewebstore.google.com/detail/last-one-click/jomapffkhcdpnodaffobmpfofnnaihnd
- 入手・紹介ページ: https://shibuhachi.works/last-one-click/
- 使い方は [extension/README.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.2.0/extension/README.md)、プライバシーポリシーは [docs/PRIVACY.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.2.0/docs/PRIVACY.md)
- 拡張でできることは、見本の記事 [templates/note](https://github.com/shibuhachi-works/last-one-click/tree/v0.2.0/templates/note)・[templates/note-paid](https://github.com/shibuhachi-works/last-one-click/tree/v0.2.0/templates/note-paid) をフォルダごとドロップするか、「GitHub から読み込む」で読み込んで試せます

## 変えていないもの

- note の下書きの作り方。note に入れるときの動きは v0.1.8 と同じです
- 入れるときに求める権限(`host_permissions`)。`cookies` 権限は持ちません。記事を送るサーバーを持たないこと、公開ボタンを押さないこと
- 「投稿する」「有料で公開する」「更新する」「下書き保存」「確認画面へ」は押しません。最後の 1 クリックは人が押します

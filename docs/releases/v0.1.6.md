# v0.1.6

有料記事の下書き(「有料」と価格、有料エリアのライン)まで入れられるようにした版です。現在は note に対応しています。

## 変わったこと

- md の front matter に `price: 300` のように書くと、公開設定で記事タイプの「有料」を選び、価格を入れるようにしました(ポップアップの「価格(有料)」の欄で直せます)
- `price` と一緒に、本文に `<!-- ここから有料 -->` だけの行を書くと、公開設定で「有料エリア設定」を押し、その行の直前の段落のすぐ下に有料エリアのラインを引いて止まるようにしました
  - 印が無ければ、これまでどおり「有料エリア設定」は押しません。どこから有料にするかは note の画面で決めてください
  - 公開設定を「キャンセル」で閉じたときや、下書きを保存して開き直したときは、有料・価格と有料エリアのラインが note 側で消えます。バナーの「もう一度入れる」で入れ直せます
  - セールの設定には触れません
- 有料記事の見本 [templates/note-paid](https://github.com/shibuhachi-works/last-one-click/tree/v0.1.6/templates/note-paid) を足しました(`price` と `<!-- ここから有料 -->` の使い方)
- 診断(「拡張機能の設定」→「診断(動かないとき)」)の「コピー」を押したとき、コピーできたことをボタンの上に「コピーしました ✓」と出すようにしました(少したつと元の「コピー」に戻ります)
- 診断のレポートに、節「ログイン中のアカウントの手がかり」を足しました(アイコンらしい画像・プロフィールらしいリンク・ページに埋め込まれたデータのキー・メニューを開くボタンが、どこにあるか)。名前・ID・アイコンの URL などの中身は出さず、レポート全体からも伏せます
- 「拡張機能の設定」のバージョン表示の下に、使い方の記事(note)へのリンクを足しました(新しいタブで開きます)

## 変えていないもの

- 権限(`host_permissions`)、note の Cookie・パスワードに触れないこと、記事を送るサーバーを持たないこと、公開ボタンを押さないこと
- 「投稿する」「有料で公開する」は押しません。最後の 1 クリックは人が押します

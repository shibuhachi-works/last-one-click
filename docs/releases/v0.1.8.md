# v0.1.8

ポップアップと編集画面の表示を、手順どおりに上から読めば分かる形に整理した版です。公開済みの記事を、md の内容で書き換えられるようにもしました。現在は note に対応しています。

## 変わったこと

- ポップアップを、手順の 3 つ(① ファイルを入れる ② 入れる内容を確かめる ③ 下書きを作る)に分けて並べ直しました
  - md を入れる前は、② に「md ファイルを入れると、ここに内容が出ます。」と出し、②③ を薄くして、作成のボタンを押せなくします
  - ② のタイトル・ハッシュタグ・マガジン・価格は、普段は短い一覧で出し、「直す」で直せます
  - 「本文の確認を飛ばして、公開設定まで進む」は「記事の設定」の中に移しました
  - 「本文の画像を入れる」「URL だけの行を埋め込みにする」のチェックを外し、いつも入れる・埋め込むようにしました(前に外していた人も入るようになります)
  - いちばん上の行に「使い方」のリンクを、いちばん下に版をいつも出すようにしました
- すでにある記事(公開済み・下書き)の編集画面でポップアップを開くと、「この記事を書き換える」で、その記事を md の内容で書き換えられるようにしました
  - タイトル・本文(今の本文を消してから)・目次・本文の画像・埋め込み・見出し画像を入れて止まります。ハッシュタグ・マガジン・価格・有料ラインは入れません
  - 拡張は「更新する」「下書き保存」を押しません。保存せずに閉じれば、記事は変わりません
  - front matter に `note_url`(書き換える記事の URL)を書くと、別の記事を開いていたときは書き換えません
- front matter に `note_account`(記事を作る note のアカウントの ID)を書けるようにしました。ログイン中のアカウントと違えば、何も入れずに知らせて止まります
- front matter に `target:`(入れる先)を書けるようにしました。`note` 以外を書いた記事は、note の下書きを作らずに止まります(ほかのサイトに出す記事を、うっかり note に入れないため)
- 本文の HTML コメント(`<!-- … -->`)を、下書きに入れる前に取り除くようにしました。自分用のメモが本文に入りません
- 「GitHub から読み込む」(上級者向け)は「拡張機能の設定」の中に移し、PR の URL(`…/pull/123`)も貼れるようにしました。その PR の `article.md` を、PR の最新のコミットの中身で読みます。GitHub トークンの欄は、すぐ下に置きました
- 公開設定を入れるとき、note が「タイトル、本文を入力してください」と出したら、閉じて少し待ってから押し直すようにしました(3 回まで。今までは止まっていました)
- 編集画面のバナーとポップアップの文を短くしました。いつも見える所は「何が起きたか」「次に何をするか」の 2 行です。バナーの見出しは「Last One Click for note」にしました
- ポップアップの知らせ(成功・エラー)を、押したボタンのすぐそばに出すようにしました

- 入手・紹介ページ: https://shibuhachi.works/last-one-click/
- 使い方は [extension/README.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.8/extension/README.md)、プライバシーポリシーは [docs/PRIVACY.md](https://github.com/shibuhachi-works/last-one-click/blob/v0.1.8/docs/PRIVACY.md)

## 変えていないもの

- 権限(`permissions` と `host_permissions`)。`cookies` 権限は持ちません。記事を送るサーバーを持たないこと、公開ボタンを押さないこと
- 「投稿する」「有料で公開する」「更新する」は押しません。最後の 1 クリックは人が押します

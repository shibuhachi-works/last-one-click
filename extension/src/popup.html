記事の設定

拡張機能の設定

GitHub から読み込む

記事のフォルダの URL か、PR の URL(…/pull/123)を貼ります。

要る権限は「Contents: Read」と「Pull requests: Read」です。
トークンはこの拡張の中にだけ保存し、GitHub にだけ送ります。

selectors/note.json の URL

普段は空のままにしてください(記事の URL ではありません)。

診断(動かないとき)

note のエディタのタブで押すと、画面の部品の一覧をコピーします。
記事の本文やログイン情報は含みません。

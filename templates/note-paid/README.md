# note の有料記事の見本

Last One Click(Chrome 拡張)で、note の**有料記事**の下書きを作るときの、md ファイルの見本です。[article.md](article.md) をダウンロードして、中身を書き換えて使えます。

**v0.1.6 から使えます。** それより前の版では、`price` は読まれず無料の下書きになり、`<!-- ここから有料 -->` の行が本文に文字のまま入ります。

無料の記事の見本と、書き方の全体は [../note](../note/README.md) にあります。

## この見本でできること

- front matter の `price: 300` で、公開設定の記事タイプを「有料」にして、価格を入れる
- 本文の `<!-- ここから有料 -->` の行の位置に、有料エリアのラインを引く(印の直前の段落のすぐ下)

どちらも、バナーの「公開設定を入れる」を押したときに入ります。有料・価格を入れたら、公開設定の画面でいったん止まります。ハッシュタグ・マガジン・価格を確かめてから、バナーの「有料ラインを引く」を押すと、ラインを引いて止まります(v0.2.0 から。前の版は、確かめずにラインまで進みます)。「投稿する」は自分で押してください。

## 書き換える前に試す

1. 「拡張機能の設定」で「上級者向けの設定を表示する」にチェックを入れる
2. 画面の上の「GitHub から読み込む」を開いて、欄に `https://github.com/shibuhachi-works/last-one-click/tree/main/templates/note-paid` を貼り、「読み込む」を押す
3. 「価格(有料)」の欄に `300` が入ったことを確かめて、「note の下書きを作成」を押す
4. 下書きができたら、バナーの「公開設定を入れる」を押す

試したら、公開せずに下書きを消してください。

## 書き換えるときの決まり

- `price` は 1 以上の整数(円)。上限・下限は note の画面の決まりに従う
- 印(`<!-- ここから有料 -->`)は 1 つだけ。本文の最初には置けない(前に無料で読める部分が要る)
- 印の直前は文字のある段落にする。同じ文字の段落をほかに置かない
- 返金申請・セールは拡張では設定しない。公開設定の画面で自分で設定する

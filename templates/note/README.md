# note の記事の見本

Last One Click(Chrome 拡張)で note の下書きを作るときの、md ファイルの見本です。[article.md](article.md) をダウンロードして、中身を書き換えて使えます。

## 使い方

1. [article.md](article.md) を開いて、右上のダウンロードのボタン(Download raw file)で保存する
2. 文字だけを保存できるアプリ(Windows のメモ帳、Mac のテキストエディットの「標準テキスト」など)で開いて、書き換える
3. 名前の最後を `.md` のまま保存する
4. 拡張の画面に、md ファイルと見出し画像をドラッグ＆ドロップして、「note の下書きを作成」を押す

公開ボタン(「投稿する」)は、拡張は押しません。最後は自分で確かめて押してください。

## 書き換える前に試す

この見本は、拡張でできること(太字・目次・URL の埋め込み・見出し画像・ハッシュタグなど)を全部入れてあります。書き換える前に、そのまま下書きにして見た目を確かめられます。

1. 拡張の設定で「上級者向けの設定を表示する」にチェックを入れる
2. 「GitHub から読み込む」の欄に `https://github.com/shibuhachi-works/last-one-click/tree/main/templates/note` を貼る
3. 「記事の先頭に目次を入れる」と「URL だけの行を埋め込みにする」にもチェックを入れて、「note の下書きを作成」を押す

`magazine` の行の「マガジンの名前」は note に無いので、公開設定でマガジンを選ぶところで拡張が知らせて止まります。試したら、下書きは消してください。

## 先頭の `---` で挟んだ所

| 項目 | 書くこと |
|---|---|
| `title` | 記事のタイトル。書かないときは、本文の最初の `# 見出し` がタイトルになる |
| `hashtags` | ハッシュタグ。`[タグ1, タグ2]` のように並べる(`#` は付けても付けなくてもよい)。省略できる |
| `magazine` | 入れたいマガジンの名前。note のマガジン名と一字一句同じにする(違うと拡張が知らせて止まる)。使わないときは、この行を消す |
| `thumbnail` | 見出し画像のファイル名。GitHub から読み込むとき、md と同じフォルダの画像を見出し画像にする。md ファイルを拡張にドラッグ＆ドロップするときは、画像も一緒に落とすので、この行は使われない(消してもよい) |

`#` から後ろは、メモ(コメント)として読み飛ばされます。

## 本文

- 本文の最初の見出しは `##` から始める(`#` はタイトルに使われるため)
- 表は note に入らない。表にしたい内容は箇条書きにする
- 使える書き方の一覧は、リポジトリの [README.md](../../README.md) の「本文で使える記法」にある

## 見出し画像

見出し画像(サムネイル)は、md と一緒に拡張の画面にドラッグ＆ドロップする。1280×670 にしておくと、トリミングなしで全体が使われる。

[thumbnail.png](thumbnail.png) は 1280×670 の見本の画像。大きさの目安にして、自分の画像に差し替えて使う。

# note の記事の見本

Last One Click(Chrome 拡張)で note の下書きを作るときの、md ファイルの見本です。[article.md](article.md) をダウンロードして、中身を書き換えて使えます。

## 使い方

1. [article.md](article.md) を開いて、右上のダウンロードのボタン(Download raw file)で保存する
2. 文字だけを保存できるアプリ(Windows のメモ帳、Mac のテキストエディットの「標準テキスト」など)で開いて、書き換える
3. 名前の最後を `.md` のまま保存する
4. 拡張の画面に、md ファイルと画像をドラッグ＆ドロップして、「note の下書きを作成」を押す(記事のフォルダや ZIP をそのまま落としてもよい)

公開ボタン(「投稿する」)は、拡張は押しません。最後は自分で確かめて押してください。

## 書き換える前に試す

この見本は、拡張でできること(太字・目次・URL の埋め込み・見出し画像・ハッシュタグなど)を全部入れてあります。書き換える前に、そのまま下書きにして見た目を確かめられます。

1. 「拡張機能の設定」で「上級者向けの設定を表示する」にチェックを入れる
2. 画面の上の「GitHub から読み込む」を開いて、欄に `https://github.com/shibuhachi-works/last-one-click/tree/main/templates/note` を貼り、「読み込む」を押す
3. 「読み込みました。」と出て、読み込んだ内容の欄に見本の md が入ったことを確かめる
4. 「記事の設定」の横に「(目次・埋め込み・画像)」と出ている(既定でこうなっています)ことを確かめて、「note の下書きを作成」を押す

見本の `magazine` の行はコメント(先頭が `#`)にしてあるので、マガジンには入れずに公開設定まで進みます。試したら、下書きは消してください。

## 先頭の `---` で挟んだ所

| 項目 | 書くこと |
|---|---|
| `title` | 記事のタイトル。書かないときは、本文の最初の `# 見出し` がタイトルになる |
| `hashtags` | ハッシュタグ。`[タグ1, タグ2]` のように並べる(`#` は付けても付けなくてもよい)。省略できる |
| `magazine` | 入れたいマガジンの名前。note のマガジン名と一字一句同じにする(違うと拡張が知らせて止まる)。見本ではコメント(`# magazine: …`)にしてあるので、使うときは先頭の `# ` を消す |
| `price` | 有料の記事にするときの価格(円)。`300` のように 1 以上の整数で書く。公開設定で「有料」を選んで価格を入れ、「有料エリア設定」の手前で止まる(どこから有料にするかは note の画面で決めるか、下の「どこから有料にするか」の印を本文に書く)。見本ではコメント(`# price: …`)にしてあるので、使うときは先頭の `# ` を消す。書かなければ無料のまま |
| `thumbnail` | 見出し画像のファイル名。GitHub から読み込むときと、記事のフォルダ・ZIP をドロップするときは、md と同じフォルダの画像を見出し画像にする。md と画像をばらばらにドロップするときは、この行は使われない(消してもよい) |

`#` から後ろは、メモ(コメント)として読み飛ばされます。

### どこから有料にするか

`price` と一緒に、本文の有料にしたい所の直前に `<!-- ここから有料 -->` だけの行を書くと、公開設定で「有料エリア設定」を押し、その行の直前の段落のすぐ下に有料エリアのラインを引いて止まる(「投稿する」は自分で押す)。印の行は本文には入らない。

- 印は 1 つだけ。本文の最初には置けない(前に無料で読める部分が要る)。`price` が無いとエラーになる
- 印の直前は、文字のある段落にする(画像や区切り線のすぐ後ろだと、場所を決められずに「手でラインを引いてください」と出る)。同じ文字の段落がほかにあるときも同じ
- コードのかたまりの中に書いた印は、文字のまま残る
- 見本の本文には印を入れていない(入れると見本が有料の記事になるため)。有料の記事の見本は [../note-paid](../note-paid/README.md) にある

## 本文

- 本文の最初の見出しは `##` から始める(`#` はタイトルに使われるため)
- 表は note に入らない。表にしたい内容は箇条書きにする
- `<!-- … -->` で囲んだ所は、自分用のメモとして読み飛ばされ、下書きに入らない(v0.1.8 から。`<!-- ここから有料 -->` だけの行は、上の「どこから有料にするか」の印になる)
- 使える書き方の一覧は、リポジトリの [README.md](../../README.md) の「本文で使える記法」にある

## 見出し画像

見出し画像(サムネイル)は、md と一緒に拡張の画面にドラッグ＆ドロップする。1280×670 にしておくと、トリミングなしで全体が使われる。

[thumbnail.png](thumbnail.png) は 1280×670 の見本の画像。大きさの目安にして、自分の画像に差し替えて使う。
